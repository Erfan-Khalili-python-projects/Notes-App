# 📝 Notes App

A simple and clean **Notes Application** built with **Python & PySide6**.

## Features

* Create and manage notes
* Edit title and description
* Save changes
* Undo changes
* Delete notes
* Persistent storage using JSON
* Clean pink-themed UI

## Tech Stack

* Python
* PySide6
* JSON

## Run

```bash
python main.py
```

> `venv/` should be excluded from Git using `.gitignore`.
